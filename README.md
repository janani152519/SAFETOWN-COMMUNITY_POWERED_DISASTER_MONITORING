# ⚠ SafeTown — Real-Time Disaster Alert & Community Safety Platform

SafeTown is an interactive, real-time alert dashboard that allows users to **view live disaster warnings**, **post community alerts**, explore historical events, and track **leaderboard rankings for active contributors** — built with Tailwind CSS, Leaflet Maps, and Vanilla JavaScript.

---

## 🚀 Features

### 🌍 Live Disaster Map
- Real-time markers on map (Leaflet.js)
- Popups showing severity, type, and location

### ⚡ Live Alert Feed
- Auto-scrolling alert carousel
- Updated list of current emergencies
- Severity tag + status verification

### 📝 Post an Alert
- Users can report new incidents
- Severity levels: `Critical`, `Warning`, `All Clear`
- Rewards users with leaderboard points

### 🏆 Leaderboard Ranking
- Tracks top community reporters
- Auto updates using localStorage

### 🗂️ Previous Information Archive
- Historical disaster cards
- Solved/Unsolved status tracking

### 🔐 User Login System
- Login popup modal
- LocalStorage-based user identity tracking
- Only logged-in users can post alerts

### ☁ Notification System
- Toast alerts
- Broadcast control button
- Notification On/Off toggle

### 🌗 Dark Mode Support
- Toggle theme for UI accessibility
